# Beta 6.22 — Mapa Real + estrelas
- Google Maps JavaScript API carregada via `/api/maps/browser-key`, usando `GOOGLE_MAPS_BROWSER_KEY` do Cloudflare.
- Mapa no Durante por dia.
- Roteiro oficial com marcadores A/B/C/D e linha na ordem do roteiro.
- Descobertas de Dica Inteligente aparecem com marcador distinto.
- Localização atual aparece quando o usuário autoriza.
- Clique no marcador abre nome/endereço e navegação.
- Ao mudar o dia, o mapa acompanha.
- Avaliação reforçada: além das estrelas junto ao nome, o próprio botão Avaliar passa a mostrar a nota imediatamente.
Observação: o traçado nesta versão é visual entre os pontos. Navegação viária detalhada pode ser adicionada com Routes API.
